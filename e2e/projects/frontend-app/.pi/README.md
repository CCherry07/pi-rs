# Pi project resources

- `APPEND_SYSTEM.md` adds project rules while preserving Pi's default system prompt and tool guidance.
- `skills/react-component/SKILL.md` is loaded on demand for React implementation work.
- `skills/frontend-verification/SKILL.md` is loaded on demand when validating frontend changes.

A project `SYSTEM.md` is intentionally absent because it would replace Pi's complete default prompt rather than append project-specific guidance.
