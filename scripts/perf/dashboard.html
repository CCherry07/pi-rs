会话与内存

确定性 ID、固定文本字节数、线性 user-message 分支。read 与 fork 在不同进程运行。每次 fork 都重新准备源仓库，计时不含准备、验证和销毁。

get100 / latest50 用批次平均减少计时噪声；P95 是批次平均值的分位数，不代表每次微操作的尾延迟。分位数采用 nearest-rank。

已加载会话 RSS 是同进程加载前后实际 RSS 的差。TS 强制 GC；RSS 仍受分配器影响。本看板不把它与峰值 RSS 混用。

CLI 与适用范围

Rust 使用 release 构建。TS CLI 的实际入口与指纹写入元数据，bundled 与 unbundled 不应混为同一基线。CLI 使用临时配置，RPC stdin 在响应前保持打开。

每种实现交替先运行；没有并发压测。不清除操作系统文件缓存；后台应用、温度与调度仍可能影响结果。

这是本地合成测试，不包含 LLM 响应、网络或交互式 TUI 渲染。测试失败时报告保留已完成的样本，不把失败当作零耗时。
